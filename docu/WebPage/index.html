LLGL Sample Page

This is a small sample page to showcase WebGL support in LLGL.

Introductory Examples:

Texturing Covers the basics of loading and applying 2D textures to a 3D model. RenderTarget Renders a scene into an offscreen texture and reuses it as an input for another draw call. PostProcessing Applies a full-screen post-processing effect to a rendered scene using an offscreen render pass. ShadowMapping Generates real-time shadows by rendering the scene depth from the light's point of view. Fonts Demonstrates how to render text on screen using a generated font atlas texture. Instancing Renders many copies of the same mesh efficiently in a single draw call using hardware instancing. StencilBuffer Uses the stencil buffer to mask and combine multiple render passes, such as a portal. MorphTargets Blends between multiple mesh shapes on the GPU to animate motion of book pages. VolumeRendering Ray marches through a 3D texture to visualize volumetric data such as clouds. Physically Based Rendering (PBR) Shows a physically based shading model with metallic/roughness materials and image-based lighting. Animation Simple animation with orthogonal view projection.
